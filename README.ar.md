# محرك منتج واحد SaaS

منصة متكاملة لبيع منتج واحد: صفحة هبوط ديناميكية، دفع عبر بايبال، مساعد مبيعات ذكي، مستورد منتجات، إدارة طلبات، تنبيهات تلغرام، ولوحة تحكم للمالك مع تبديل السمة واللغة.

## المميزات

### واجهة المتجر

- صفحة هبوط ديناميكية مدعومة من قاعدة البيانات (العنوان، السعر، السعر قبل الخصم، الصور، الوصف، المميزات، القصة، دعوة ختامية)
- شبكة منتجات تربط بصفحات تفصيلية لكل منتج (`/product/[id]`)
- نافذة دفع مدمجة مع أزرار بايبال (إنشاء الطلب والالتقاط من الخادم)
- مساعد مبيعات ذكي عائم يقرأ المنتج الحالي كتعليمات نظام له
- تبديل السمة (داكن / فاتح) محفوظ في localStorage
- تبديل اللغة (إنجليزي / عربي) مع دعم تخطيط RTL
- أقسام الثقة وآراء العملاء والأسئلة الشائعة والضمان

### لوحة التحكم (`/dashboard`)

- نظرة عامة: الإيرادات، عدد الطلبات، أحدث الطلبات، المنتج النشط
- مستورد المنتجات: الصق أي رابط منتج، استخرج العنوان والسعر والصور والوصف والمميزات، عدّل مع معاينة حيّة، انشر
- مكتبة المنتجات: أعد التمييز أو أخفِ أو احذف المنتجات السابقة
- الطلبات: جدول قابل للبحث والتصفية مع سير عمل الحالة (PAID / SHIPPED / COMPLETED / CANCELLED)
- بوت تلغرام: احفظ رمز البوت ومعرف المحادثة، اختبر الاتصال، اعرض حالة البوت الحيّة
- المدفوعات: أدِر مفاتيح بايبال (المعرف / السر / الوضع)، تحقق من الصحة، امسح المفاتيح المحفوظة
- إعدادات الشات بوت: فعّل أو عطّل، اختر Gemini أو OpenAI، ضع مفتاح API والنموذج والنبرة والنظام
- الإعدادات: بدّل حماية المصادقة، حدد اللغة الافتراضية، غيّر أو أعد تعيين كلمة مرور المالك

## البدء السريع - ويندوز (نقرة واحدة)

شغّل `install.bat` مرة واحدة لإعداد المشروع:

```bat
install.bat
```

هذا السكربت يقوم بـ:

1. التحقق من Node.js و npm (يعرض تثبيت Node.js LTS عبر winget إن كان مفقودا)
2. إنشاء `.env` من `.env.example` إن لم يكن موجودا
3. إيقاف أي نسخة تعمل من التطبيق (لتجنب قفل الملفات في ويندوز)
4. تشغيل `npm install` (مع محاولة إضافية عند الفشل)
5. توليد عميل Prisma
6. تحضير قاعدة بيانات PGlite المحلية (المخطط + بيانات تجريبية)
7. تثبيت Playwright Chromium اختياريا لكشط المتاجر الثقيلة

ثم شغّل الخادم:

```bat
start.bat
```

### وسيطات start.bat

| الوسيط | السلوك |
| --- | --- |
| *(بدون)* | يفتح المتجر + لوحة التحكم في المتصفح |
| `dashboard` | يفتح لوحة التحكم فقط |
| `store` | يفتح المتجر فقط |
| `nobrowser` | لا يفتح المتصفح تلقائيا |

### المنفذ 3000 مستخدم مسبقا

إذا كان المنفذ 3000 محجوزا، يكتشف `start.bat` العملية ويعرض ثلاثة خيارات:

- **O** (فتح): يفتح النسخة الموجودة في المتصفح ويخرج
- **K** (قتل): يوقف العملية المحجوزة ويبدأ خادما جديدا على المنفذ 3000
- **N** (منفذ جديد): يبدأ على المنفذ 3001 (تحذير: قد يتعارض خادمان على قاعدة البيانات المحلية)

## البدء السريع - يدوي (لكل الأنظمة)

```bash
# 1. تثبيت الاعتماديات
npm install

# 2. ضبط البيئة
cp .env.example .env      # ثم املأ القيم

# 3. إعداد قاعدة البيانات
npx prisma db push          # أو: npx prisma migrate dev
npm run db:seed             # منتج تجريبي اختياري

# 4. التشغيل
npm run dev                 # http://localhost:3000
```

## متغيرات البيئة

| المتغير | الغرض | مطلوب |
| --- | --- | --- |
| `DATABASE_URL` | سلسلة اتصال PostgreSQL | نعم (ما لم تستخدم PGlite) |
| `APP_URL` | الرابط الأساسي للتطبيق (يستخدم للردود) | لا (افتراضي: `http://localhost:3000`) |
| `NEXT_PUBLIC_APP_URL` | الرابط العام المكشوف لمكونات العميل | لا |
| `ADMIN_PASSWORD` | كلمة مرور لوحة التحكم (احتياطي إن لم يكن هناك تجزئة محفوظة) | مستحسن |
| `SESSION_SECRET` | 32 حرفا عشوائيا لتوقيع JWT | مستحسن |
| `PAYPAL_ENV` | `sandbox` أو `live` | لا (افتراضي: `sandbox`) |
| `NEXT_PUBLIC_PAYPAL_ENV` | بيئة بايبال المكشوفة للعميل | لا |
| `PAYPAL_CLIENT_ID` | معرف تطبيق بايبال (احتياطي من البيئة) | نعم (للدفع) |
| `PAYPAL_CLIENT_SECRET` | سر تطبيق بايبال (احتياطي من البيئة، خادم فقط) | نعم (للدفع) |
| `NEXT_PUBLIC_PAYPAL_CLIENT_ID` | معرف بايبال المكشوف للعميل لعرض الأزرار | نعم (للدفع) |
| `PAYPAL_CURRENCY` | رمز العملة ISO 4217 | لا (افتراضي: `USD`) |
| `TELEGRAM_BOT_TOKEN` | رمز بوت تلغرام (احتياطي من البيئة، خادم فقط) | لا |
| `TELEGRAM_CHAT_ID` | معرف محادثة تلغرام (احتياطي من البيئة) | لا |
| `AI_PROVIDER` | `gemini` أو `openai` | لا (افتراضي: `gemini`) |
| `GEMINI_API_KEY` | مفتاح Google Gemini (احتياطي من البيئة) | للشات بوت |
| `OPENAI_API_KEY` | مفتاح OpenAI (احتياطي من البيئة) | للشات بوت |
| `AI_MODEL` | تجاوز النموذج الافتراضي | لا |
| `USE_PGLITE` | ضع `1` لاستخدام قاعدة بيانات PGlite المدمجة | لا (افتراضي: مغلق) |
| `PGLITE_DIR` | مجلد بيانات PGlite | لا (افتراضي: `./.pglite`) |

يمكن أيضا ضبط مفاتيح AI وبيانات بايبال من لوحة التحكم وتخزينها في قاعدة البيانات. قيم البيئة تعمل كاحتياطي.

## قاعدة البيانات المحلية (PGlite)

يمكن للتطبيق العمل على نسخة PGlite مدمجة من PostgreSQL، فلا حاجة لخادم قاعدة بيانات خارجي للتطوير المحلي.

ضع التالي في `.env`:

```env
USE_PGLITE=1
PGLITE_DIR=./.pglite
```

### السكربتات المساعدة

| السكربت | الغرض |
| --- | --- |
| `node scripts/preview-db.mjs` | ينشئ مخطط PGlite ويزرع منتجا تجريبيا وعينات طلبات. قابل للتكرار. |
| `node scripts/pglite-repair.mjs` | يزيل قفل `postmaster.pid` العالق بعد قتل قسري. شغّله قبل بدء خادم التطوير إذا ظهر `RuntimeError: Aborted()`. |
| `node scripts/preview-reset.mjs` | يحذف مجلد PGlite بالكامل ويعيد بنائه. استخدمه عند تلف مجلد البيانات. |

يمكن لعملية واحدة فقط استخدام مجلد PGlite في نفس الوقت. تشغيل خادمين بالتوازي على نفس المجلد يسبب تعارضا.

### متصفح Playwright (اختياري)

يستخدم المستورد متصفح Chromium بلا واجهة كخيار احتياطي للمتاجر الثقيلة. المتاجر الثابتة تعمل بدونه.

```bash
npx playwright install chromium
```

## الوصول إلى لوحة التحكم

لوحة التحكم في `/dashboard`. الزيارة غير المصادقة تُحول إلى `/login`.

تُحل كلمة المرور بالترتيب التالي:

1. تجزئة scrypt المخزنة في قاعدة البيانات (تُضبط من لوحة التحكم > الإعدادات)
2. متغير البيئة `ADMIN_PASSWORD` (احتياطي)

يمكن تعطيل حماية المصادقة بالكامل من لوحة التحكم > الإعدادات بإيقاف خيار "طلب كلمة المرور". عند التعطيل، جميع صفحات لوحة التحكم وواجهات API تكون متاحة بدون تسجيل دخول.

## سير العمل

```
المالك يلصق رابط منتج في لوحة التحكم
  -> المستورد يستخرج العنوان والسعر والصور والوصف والمميزات
  -> المالك يعدّل المسودة ويرى معاينة حيّة
  -> المالك ينشر (المنتج السابق يُحفظ في المكتبة)
  -> صفحة الهبوط والشات بوت يتحدثان فورا
  -> الزائر يتصفح المتجر ويتحدث مع المساعد الذكي
  -> الزائر يدفع عبر بايبال
  -> الطلب يُحفظ (التقاط مكرر بواسطة paypalOrderId)
  -> تنبيه تلغرام يُرسل فورا بتفاصيل الطلب
  -> المالك يدير الطلبات من لوحة التحكم
```

## ملاحظات أمنية

- **قراءة السعر من الخادم**: مسار التقاط الدفع يقرأ سعر المنتج من قاعدة البيانات، لا يثق بالمبلغ المرسل من العميل.
- **التقاط مكرر للطلبات**: الطلبات المكررة لنفس `paypalOrderId` تُكتشف ويُعاد الطلب الموجود بدون إنشاء سجل ثان.
- **كوكيز جلسة موقعة httpOnly**: الجلسات JWT (HS256) موقعة بـ `SESSION_SECRET`، مخزنة في كوكيز `httpOnly` بـ `sameSite=lax` وانتهاء 7 أيام. الكوكيز `secure` في الإنتاج.
- **الأسرار تبقى في الخادم**: سر بايبال ومفاتيح AI ورمز تلغرام لا تُرسل للعميل أبدا. فقط متغيرات `NEXT_PUBLIC_*` تُكشف.
- **تجزئة كلمة المرور**: كلمة مرور لوحة التحكم تُجزأ بـ scrypt قبل التخزين في قاعدة البيانات.
- **تبديل المصادقة**: المالك يمكنه تعطيل مصادقة لوحة التحكم بالكامل من الإعدادات. عند التعطيل، `requireAdmin()` يُعيد جلسة مدير اصطناعية بدون التحقق من الاعتماديات.
- **التحقق من المدخلات**: جميع إجراءات الخادم ومسارات API تتحقق من المدخلات بمخططات Zod قبل المعالجة.
- **قيود رفع الصور**: نقطة الرفع تحد بأقصى 5 ميغابايت وتسمح فقط بصيغ JPG و PNG و WEBP و GIF و AVIF.
